## 📋 Overview

This repository contains a highly detailed, exam-oriented roadmap for Cyber Security. It is structured topic by topic, providing definitions, types, real-world examples, and quick revision notes. 

It is designed to help students master the foundations of Information Security, Cryptography, Network Security, and Ethical Hacking.

---

## ✨ Key Topics Covered (12 Main Topics)

* **Topic 1:** Security Fundamentals (CIA Triad, AAA, Risk)
* **Topic 2:** Security Attacks & Malware (Virus, Worms, Ransomware)
* **Topic 3:** Cryptography (AES, RSA, Hashing, Digital Signatures)
* **Topic 4:** Authentication & Access Control (MFA, DAC, MAC, RBAC)
* **Topic 5:** Network Security (Firewalls, IDS/IPS, VPN, TLS)
* **Topic 6:** System & Database Security (Patching, SQL Injection)
* **Topic 7:** Web & Application Security (XSS, CSRF, OWASP Top 10)
* **Topic 8:** Risk Management & Security Policies (RTO, RPO, BC/DR)
* **Topic 9:** Security Models & Principles (Bell-LaPadula, Biba, Zero Trust)
* **Topic 10:** Ethical Hacking & Security Tools (Nmap, Wireshark, Kali)
* **Topic 11:** Incident Response & Digital Forensics (Chain of Custody)
* **Topic 12:** Final Revision & Exam Practice
